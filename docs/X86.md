# Munt386 x86 CPU core

Implementation: `src/cpu.c`. Tests: `tests/cpu/`.

## Register file

The register file is **32-bit** (`uint32_t r[8]`, `eip`, `eflags`) so the 286/386
phases can be layered on without changing access code. Today only the 16-bit
real-mode views are exercised.

| 32-bit | 16-bit | 8-bit |
| --- | --- | --- |
| EAX | AX | AH, AL |
| ECX | CX | CH, CL |
| EDX | DX | DH, DL |
| EBX | BX | BH, BL |
| ESP | SP | — |
| EBP | BP | — |
| ESI | SI | — |
| EDI | DI | — |

Segments: `ES CS SS DS FS GS`. Control: `CR0 CR2 CR3`. System: `GDTR IDTR`.
`LDTR`/`TR` are reserved for Phase 3.

## Implemented instruction groups (real mode, 16-bit)

- **Data transfer:** MOV (all forms incl. moffs, segment, imm), XCHG, LEA, XLAT,
  LAHF/SAHF, PUSH/POP (r16, r/m16, segment, PUSHF/POPF), PUSHA/POPA (80186),
  IN/OUT (imm and DX).
- **Arithmetic:** ADD, ADC, INC, SUB, SBB, DEC, CMP, NEG, MUL, IMUL, DIV, IDIV,
  CBW, CWD.
- **Logic:** AND, OR, XOR, NOT, TEST.
- **Shifts/rotates:** SHL/SAL, SHR, SAR, ROL, ROR, RCL, RCR (by 1, by CL, and
  80186 imm8 forms).
- **Control transfer:** JMP (rel8/rel16/far/r/m), all 16 `Jcc`, CALL
  (rel16/near/far), RET/RETF (+imm16), LOOP/LOOPE/LOOPNE, JCXZ, INT/INT3/INTO,
  IRET, HLT.
- **Flags:** CLC/STC/CMC/CLD/STD/CLI/STI.
- **Strings:** MOVS, CMPS, STOS, LODS, SCAS with REP/REPE/REPNE and the direction
  flag.
- **BCD/aux:** AAM, AAD, SALC.

## ModR/M decoder

`decode_rm()` implements the full 16-bit real-mode effective-address set:

| rm | default segment |
| --- | --- |
| 0 | BX+SI, DS |
| 1 | BX+DI, DS |
| 2 | BP+SI, SS |
| 3 | BP+DI, SS |
| 4 | SI, DS |
| 5 | DI, DS |
| 6 | BP (SS) or disp16 (DS) |
| 7 | BX, DS |

with `mod=0/1/2` displacement handling and segment overrides `ES CS SS DS FS GS`.
This is a real decoder — not a simplified instruction format.

## FLAGS semantics

CF, PF, AF, ZF, SF, TF, IF, DF, OF are computed exactly:

- Addition/subtraction derive AF from `(a ^ b ^ r) & 0x10`, OF from the sign
  relationships, CF from the carry/borrow out, and PF from parity of the low byte.
- Increment/decrement preserve CF and set the other arithmetic flags.
- Logic ops clear CF and OF and set SF/ZF/PF.
- Shifts set CF/OF and (for SHL/SHR/SAR) SF/ZF/PF; rotates touch only CF/OF.

Edge cases explicitly tested (`tests/cpu/test_flags.c`): `FFFF+1`, `7FFF+1`,
`8000-1`, `0000-1`, ADC/SBB with carry-in, RCL/RCR through carry, SAR sign
preservation, even/odd parity.

## Not yet implemented (tracked in `docs/ROADMAP.md`)

| Feature | Prefix/area |
| --- | --- |
| 32-bit operand size | `0x66` prefix (Phase 4) |
| 32-bit address size | `0x67` prefix (Phase 4) |
| FS/GS via `8C`/`8E` | 386 encoding (Phase 4) |
| Protected mode & descriptors | CR0.PE, GDT/IDT (Phase 3) |
| Paging | CR0.PG, CR3 (Phase 5) |
| Exceptions (PUSH fault frames) | Phase 3 |
| LOCK prefix semantics | Phase 6 (single-threaded today) |
| x87 FPU | optional; ESC consumes ModR/M only |

Encountering an unimplemented opcode raises a CPU fault (`cpu->fault`) that
reports the opcode and `CS:IP` rather than silently mis-executing — correctness
over guessing.
